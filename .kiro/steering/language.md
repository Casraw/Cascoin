# Language Conventions

## Code Comments
- All code comments MUST be written in English.
- This applies to inline comments, block comments, doc comments, and commit-style notes embedded in code.

## Documentation
- All documentation MUST be written in English. This includes:
  - Spec documents (`.kiro/specs/**/requirements.md`, `design.md`, `tasks.md`)
  - Developer docs under `doc/`
  - READMEs and design notes
- Identifiers, log messages, and user-facing strings follow the existing codebase conventions.

## Conversation
- Chat responses may follow the user's language, but any artifact written to disk (code, comments, docs) MUST be in English.
